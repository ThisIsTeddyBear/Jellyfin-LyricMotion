# TV validation (historical)

Earlier public releases enhanced the Jellyfin TV lyrics page directly. That policy is no longer current.

Starting with the 3.1.0 branch, detected TV-class clients **hard-bypass LyricMotion** and use Jellyfin's stock lyrics implementation. Current behavior, detection scope and regression expectations are documented in [TV-STOCK-BYPASS.md](TV-STOCK-BYPASS.md).
