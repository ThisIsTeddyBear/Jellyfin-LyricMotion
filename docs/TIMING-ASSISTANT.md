# Timing assistant

Use the timing chip when a lyric file is consistently early or late. Adjust in `0.1s` steps, or choose **Sync lyric to now** and tap/click a lyric at the moment it begins. Positive offsets delay lyrics; negative offsets show them earlier.

The correction is stored only for the matching lyric timeline, so replacing a lyric file does not incorrectly reuse an old adjustment. **Reset** returns the file to its source timing.

The assistant corrects a fixed offset. Repair source lyrics when their timing progressively drifts.
